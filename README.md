# 🌐 Personal Portfolio Website

A modern, responsive portfolio website built using **HTML, CSS, and JavaScript**. It showcases my skills, projects, and contact information with a clean UI, smooth scrolling, and a dark/light theme.

## ✨ Features

- 🏠 Responsive Home Section
- 👤 About Me Section
- 💻 Skills Section
- 📞 Contact Form
- 🌙 Dark & Light Theme Toggle
- 📄 Download Resume Button
- 🔗 GitHub & LinkedIn Links
- 📱 Mobile Responsive Design
- 🎨 Modern Glassmorphism UI
- ⚡ Smooth Scrolling Navigation
- 💾 Contact Form Data Stored in Local Storage

## 📥 Installation

1. Clone the repository

```bash
git clone https://github.com/hrithiknagesh/portfolio.git
```

2. Open the project folder

```bash
cd portfolio
```

3. Open `index.html` in your browser.
